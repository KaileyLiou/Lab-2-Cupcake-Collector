# Lab 2: Cupcake Collector

A simple platformer game created with Python and Pygame for my A.I. for Game Programming class.

In this game, the player controls a robot sprite who jumps across platforms to collect cupcakes. The goal is to collect as many cupcakes as possible while navigating the platforms without falling.

## Features

- Keyboard-controlled movement and jumping
- Multiple platforms at varying heights
- Two types of collectible cupcakes (worth 1 and 2 points)
- Collision detection with platforms and cupcakes
- On-screen score display

## How to Play

Use the left and right arrow keys to move, and use the up arrow key to jump.
